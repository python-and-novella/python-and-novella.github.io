# Blessed的中文入门教程

## 0 前言

Blessed是一个更低级的TUI框架。说它低级并不是说功能不够强大，而是因为其提供的方法更直接，可以做到直接操作每个字符。当然，这么做的话，自然有取舍之处，那就是默认提供的功能没有其他高级框架丰富，却也让实际开发不怎么受框架限制，可以更加随心所欲。

虽然功能不是特别复杂，但官方没有中文教程，因此笔者将依照官方手册，按照学习顺序，制作了中文入门教程。
