#### 苏菲（Sophy）：

24岁，星际商人，女强人，天生个性独立，做事干练，敢爱敢恨，不服输，内心坚强的她有时又会有软弱的一面。长发的她喜欢把辫子扎起来，穿上舒适的衣裤，这样干活也不麻烦；但是，当她不忙的时候，还是会换上她心爱的长裙，放开秀丽的长发，给人以端庄典雅的感觉。她的妹妹随母亲一起，在离开地球时走散，但她不知道。

苏菲和罗一（那时的代号E）的渊源，苏菲在一次与父亲争吵后，得知了和妹妹以及母亲走散的事实，暗自下决心去寻找。终于在一次离家出走后（18岁），决定去地球。她不顾警告，闯入地球，但飞船故障，一时无法起飞，而她也受伤了，在这时，她被罗一所救(是因为此时罗一突然掌握超能力，预测到受伤的苏菲会被抓起来死去，就伸出援手)，情窦初开，他们一见钟情，飞船修好后，苏菲带着罗一离开地球，在空间站两人走散，从此苏菲要找到人多了一个。
