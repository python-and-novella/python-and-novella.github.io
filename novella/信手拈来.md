# 信手拈来（2025）

## 0 前言

创作教程之余，笔者也在思考，于是，一些想法在不经意间萌生。除了学习技术，各位读者还应该沉下心想一想，工作和学习不止眼前的忙碌，还有选择的方向，更离不开照亮前路的灯指引之光。

## 1 尽管视频教程更简单，但我还是推荐你看文字教程

在B站各种视频教程大行其道的今天，我还在创作“传统”教程，想必不少人在看到之后想敬而远之。

但是，今天我要说的是，文字教程可能“无趣”，但你要是想好好学习，文字教程可能比视频教程更适合你。

**视听丰富的视频，让你不经意间失去专注，也浪费了你更多时间。**

在短视频泛滥的今天，不知道你有没有想过，为什么你更喜欢看视频教程，而非文字教程？

视频教程直观、手把手教学固然是优点，但有一个容易被忽视的特点，可能连你也没想过。那就是：你已经习惯了从视频中获取知识。

可是，这又有什么问题吗？

你固然喜欢视听丰富的教程，没什么事情做的时候可以看一眼，忙的时候可以放在一边听，似乎是个忙里偷学的好选择。

但是，当你没有专注在学习中时，教程带着的丰富信息就会被你忽略，而你在听过、看过之后，脑中本能以为这段内容看过，很容易忽略掉其中的重要信息。此外，视频教程的制作者大多啰嗦，让你不自觉地想要快进。但这样又容易漏掉关键信息，不得不反复观看前面的内容，无形中浪费了不少时间。

相比之下，虽然文字教程看上去没那么有趣，需要你持续专注其中，但是，一旦你开始专注学习，你所能接收到的只有文字，你的听觉会因此放空，大脑能留出更多处理信息的能力，专注于思考。

因此，一旦习惯了文字教程，你会比在观看视频教程时更加专注，学习效果更好。

另外，编程教程需要在学习的同时实操代码，才会记得更牢。但是，大部分人的大脑一般是单线程工作效率最高，写代码的同时还要听视频内容的声音，代码和声音中，必然有一个不是百分百专注，效果势必大打折扣。

**是文字教程，同时也是手册，更是学习笔记。**

学习不是看一遍就能记住，哪怕敲代码已经娴熟，但总会遇到生疏的知识点，需要上网查找相关资料，或者查阅手册。

文字教程，会通过简练的语言总结要学习的内容，并将需要用到的相关资料的出处标明，不是手册，胜似手册。

相比于视频，全文搜索可以让文字教程发挥出堪比手册的效果。尤其是我写的很多教程都附带了简洁的示例代码，可以直接复制使用，对比视频教程需要下载源码或者手动输入视频中的示例，方便不少。

此外，我的教程也有类似学习笔记的效果。前面说过的示例是一部分，另一部分就是，我的教程不会完全照抄官方教程、手册，而是通过分析相关知识点，将相似、相关的一类内容总结分析，得到一个汇总之后的结果。比如，在《Qt For Python 札记》中，分析了Qt程序的三种程序类之后，依次写了对应类的示例，对比异同，可以让你更清晰地了解Qt程序的三种程序类，哪怕后续经常使用的只是其中一种，但有时间回顾该章节的话，总能第一时间了解其异同。

**总结**

总的来说，很多人都知道沉迷短视频不好，但鲜有人做到不刷短视频。而很多人看视频教程喜欢挂在后台当音乐听，鲜有人承认他们没有认真学习，都是一句“看过了”、“学过了”掩饰着自己的不专注。

唯独那些专注读书（只看文字）的人，他们看过的书，过目不忘。他们读书的同时，大脑也在飞速思考。不像看视频时候大脑好像很愉悦、放松，可看完一遍总觉得效率大打折扣。

从现在开始，试着安安静静地看一本书或者一部文字教程，测一测自己的专注力能否坚持到10分钟。

## 2 因为能力不足而学习是对的，因此花冤枉钱是不对的

在这经济下行、大部分人抱怨工作不好找的时候，大家的焦虑促使好学者寻求一切提升自我的机会，伺机蛰伏，以求厚积薄发。

然而，有些人却趁机大发“国难财”，让那些原本捉襟见肘的学习者雪上加霜，这就不值得称道了。

都说“活到老，学到老”，终身学习是一个好习惯，而我在创作教程时，也需要不断学习，才能输出有用的内容。

但是，很多人却将敛财的黑手伸向心怀焦虑的学习者，通过贩卖焦虑来让他们接受所谓的高价教程，一点也不在乎他们的学习效果，这么做属实为人不齿。

随处可见AI让普通人赚大钱的文章，可实际赚钱的只有那些卖AI课程的人，真正学AI的普通人，赚钱者寥寥无几。这也从侧面反映出一个事实：如果有人说做某事很赚钱而他却不做的时候，那就说明这件事并不赚钱。

说到这里，肯定有人会反驳我，说我就是做付费教程的，这样贬低别人的付费教程，说到底就是为了推销自己而编的瞎话。

这里我就要为自己辩解一下。虽然我也写付费教程，但我更多是出于知识的分享，而非炒作所谓的“不学就落后”、“学了就赚大钱”。

而且，我的付费教程并没有那种高价教程。尽管我一开始写的几本参考了微信读书的电子书定价，但我也没有定较高价格，而是参照中低价位的电子书。后续我更是采用类似网文单章付费的设计，将章节内容拆分，让只是需要部分内容的读者可以灵活购买，无需整本付费，极大减轻了读者的负担。

其实，很多时候，不知道自己的方向是否正确，去学习某种技能时，都是一种试错。花那么多钱去押注，不如尽量减少试错的成本。

试想一下，你要是花了几百块买了所谓的课程之后，发现自己不喜欢相关内容，或者学了几天没有效果，这几百块打了水漂，你心不心疼？

主动学习值得肯定，但在拮据的时候还要花那么多钱去押注，这个选择算不上明智。

## 3 做笔记是个好习惯，如果你不喜欢做笔记，说明你不想认真学习（更新中）

从上学开始，老师就要求学生做笔记。可是，等进了社会，职场人闲暇之余看看书，学些技能的时候，做笔记的习惯好像丢掉了一样，其中的变化值得深思。

以学习Python为例，不知道各位有没有做笔记的习惯，起码我一开始没有。

不过，等后面我发现我时间长不复习，前面学过的知识开始遗忘、需要重新学习的时候，才发觉做笔记的重要性，也开始反思自己为什么不喜欢做笔记。

众所周知，Python是比较简单的，而我一开始也抱着这样的想法，觉得做笔记没有必要。然而，事实证明，永远不要轻信自己的记忆力。

编程语言学起来容易，忘得时候也快，除非一直在用。我是没有那种将爱好当工作的经验，Python只是我的爱好，所以，工作一旦忙起来，Python就很少碰了。

时间一长，我再次打开Python代码的时候，原本熟悉的代码居然变得有些陌生，我不得不再次打开好不容易理解的教程，重走学习之路。

好记性不如烂笔头，可都是在电脑上写代码的Python，总不至于还要买个本子，在上面写写画画吧？

在学习之余，我脑海中突然冒出一个念头：既然我能理解那些难点，何不将我理解的内容写下来，写成教程，给其他初学者看？

于是，我便开始着手学习NiceGUI，同时构思《NiceGUI的中文入门教程》。

没错，《NiceGUI的中文入门教程》是我创作的付费教程，同时也是我的学习笔记。

事实证明，这个特殊的学习笔记，在我时隔多日再次使用NiceGUI时，帮助我回想起那些学过知识。每次当我不知道某个功能的用法时，我都会搜索自己创作的教程，很快就能想起自己踩过的坑。

在此，我也建议各位学习者，不管你是在看我的教程还是别人的教程，可以在学习的同时，做一些学习笔记。当你能写出条理清晰的笔记时，就证明你已经学会了相关知识。同时，这些笔记也会在你需要重新学习时，帮助你快速回想起你已经学会的相关知识，节约你的时间。

## x 创作要求

题材不限于技术，可以是文学、日常生活、哲学。

文章采用三段式结构，标题、开头要吸引人，中间展开要有清晰的结构，结尾要适当总结并且有金句。

篇幅不用太长，1千字左右即可，每周至少一更。
