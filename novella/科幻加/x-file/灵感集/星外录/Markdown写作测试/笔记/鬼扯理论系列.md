 

时间线收束理论：（实际上是玄学，根据时间河流理论，未来存在无数可能性，时间线收束更像是有时间能力的人对未来刻意改变，或者巧合）

在一定情况下，可以做到无论如何改变，都会最终到达统一的重点。实际情况是，在合理的误差行动范围内，不同种类的行动不会影响结局，会有神奇的力量让结果回归，就好像各条时间线都会收束一样。

人的过去是唯一的，未来是不确定的，但有了时间线收束理论，就可以在一定范围内预测人的未来。因此，MAX的能力虽然弱，但可以很明确。罗一的能力虽然强，没有收束理论的支持，也会像无头苍蝇一样，计划执行偏差太多就会导致结果大变样。而罗一要准确预测未来，就要花费大量能力是时间去遍历未来的可能性，有了收束理论就能节省不少。

时空域有限理论：对于单个事件而言，存在边界有限的时空领域，在该领域内，对象产生的影响才会对被观察的事件有影响，边界外，产生的影响较小，可以忽略不计，记作无影响。同样的，对于任意事件，进入该事件的有限时空域的对象才算作对该事件有影响的对象，也适用。

时空有限元理论：对于任意对象，能对时空产生影响的范围可大可小，划分到最小范围时，产生的影响可以套用简单分析模型，该范围称为最小时空域，通过划分最小时空域的方法来分析一些复杂对象合集的时空发展的方法，称为时空有限元分析。

时间河流理论：（时间能力的科学理论基础，加上平行宇宙才算完整解释，平行宇宙也是后续发展才加的）

时间对于个人的表现之所以是“不可逆”，是因为时间对于个人来说，就好像一条河流一样，而河流的流向和实际感受的时间的流向相反，下游是过去，上游是未来，个人就是河流的石头，只能看到时间向下流去，即只能看到上游的水不断过来，像要控制时间，就要把石头自己的时间坐标变动，把石头变成小船，当小船加速顺游而下，就能看到曾经流过自己的河水，就是穿越到过去，但实际上这些河水已经流过自己，所以即使去改变也不能影响到当前位置的自己，所以过去不可改变（其实可以改变，只是改变了非自己存在的平行宇宙的过去，因此同时存在两个自己就不算违反规律）；而上游的水还没流经自己，因此对上游的改变可以影响到自己，因此可以改变未来。

但是，基于之前的理论，人只能穿越到未来，不能逆向返回到原来的宇宙的原来时间点，这样就会造成一个人的存在出现时间断层（人突然消失一段时间），而这种改变未来对自己并没有太大优势（因为时间断层的存在，往往会产生更多不利影响），因此，要想真正的改变未来，就要用类似虚位移一样的虚穿越（观测不同的平行宇宙，得到连续的未来定格动画），只看未来（平行宇宙的未来）的结果，想办法让当前宇宙达到那种效果，实现另一种改变未来的方法。

基于上述改变未来的方法，发现了存在连续性定律，对于当前宇宙，穿越到平行宇宙是困难的；如果要改变当前宇宙的过去，势必破坏存在连续性（同一独特物质存在两份，无法共存），因此过去无法改变；改变未来要造成存在断层，只能让当前物质到平行宇宙，一段时间后再返回来实现，而不同平行宇宙的当前物质在太近的时候会产生强大排斥力，而物质本身的时间流速很难改变；因此，改变未来常用上述虚穿越的方法，时间无法倒流，稍微的过去和未来也是不同平行宇宙的表现，不是真实的过去和未来，当前宇宙的过去倒是可以通过记录准确得知。

四维生物在三维空间的表现：（空间能力的科学能力基础）

四维空间多出一个维度，这个维度就是定位平行宇宙的关键坐标，因此，本质上每个平行宇宙对应一个第四维坐标，切换第四维坐标，使用特殊方式加速时间流动（并非真的加速，只是嗅探到可以准确预测未来的平行宇宙），并使用虚位移的方式，可以实现查看未来一段时间发生的事情，坐标不同，对应的平行宇宙（可能性）就不同，罗一的能力就是这种形式。

人脑骇客只是切换第四维坐标，通过与三维空间中的人叠加，进入一种特殊的叠加态（类似于虚穿越），进而影响三维空间的人，实现对人的远程控制，因为第四维坐标是平行宇宙，可以做到三维空间中非同一坐标，四维空间中坐标映射的三维坐标相同，后来这种技术被用于实现传送技术，打开虫洞（后来证实，第四维也不是平行宇宙，虫洞就是三维坐标不同，但可以四维坐标相同，而且有规律可循，也有稳定的方法实现，研究成果来自四维空间技术研究所）。 

基于四维空间实现的传送技术，与人脑骇客使用叠加态影响别人的方式（事后证实这也只是别人的猜测，人脑骇客也是和罗一一样，探测同一时间其他平行宇宙的人的角色id罢了，控制别人是基于穿越带来的金手指--角色代入）不同，传送技术使用的是瞬态的跳跃特性，使用不会影响别人的超短时间瞬态可控跳跃，把三维坐标切换的想要切换的地方，实现传送，掌握这种跳跃控制技术后，之前虫洞商人那种没头苍蝇似的乱撞成为过去，虫洞商人的生意因此没落，虫洞的建立便交给了四维空间技术研究所。

《左手能力——非惯用手的特殊能力的研究》：罗一除了特殊的时间能力和右手常用的但是弱于一般战斗系的通用超能力外，左手也在后期觉醒了特殊能力。罗一的左手能力是加强和改变，可以加强正常能力，也可以改变正常能力的特性，如冰属性变火属性，简单来说就是催化（加强、转变）。当然，这个能力也有副作用，会短时消耗较多体力导致眩晕，一段时间内无法再次使用超能力（类似于冷却时间）。

时间能力：时间旋钮，可以正转、反转来预知、探知发生在未来、过去的事情（虚拟位移状态）。限制，常规的冷却时间，理论上时间跨度无限，但受限于体力值和精确度，太长的跨度性价比不高。时间倍速，可以让自身时间流速变为其他人的二正负十次方倍。

引力胡克定律：不同于常规的引力规律，引力胡克定律仅适用于特定的引力波。该引力遵循胡克定律，发射相同引力波的两个物体由于自聚性，存在引力等于K*x，K为引力胡克系数，x为距离，x取值（0，X），X为引力边界值，超过边界值胡克定律失效，引力将以特定规律急剧减小。

引力胡克定律的应用——引力双子球（Duo-ball）：类似于双子星，两个互相吸引的小球，可以充当玩具或者武器，类似于双节棍加流星锤的玩法，只不过中间没有实体线束缚。
