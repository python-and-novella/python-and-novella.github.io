# Python入门一步到位——年轻人的Python学习方法

## 前言

（以下内容精修一下）受王小波启发，本书主要是写小说之余学习Python的一个过程笔记，介绍了自己选择工具、框架的择优过程，并着重介绍一些自以为还算好用的工具、语法，希望那些想要入门的年轻人少走弯路，快速便捷搭建一套自己的工作流。

本书并不是告诉你应该这么做，而是告诉你可以这么做，人生苦短及时行乐，学习本该快乐。

本书也不会大篇幅介绍基础语法，官方文档虽然枯燥但是准确而专业，看完入门篇之后可以自己学基础语法，然后回来看后续的内容。

现代化工具指南：入门既可以脚踏实地，也可以站在巨人肩膀。pdm、poetry等包管理工具，其他基础开发工具、集成环境推荐：vscode及相关开源自由版本（含code-sever等服务器部署版），winPython、anaconda等懒人环境，conda系列企业级包管理器。

巧妙但不一定用得到：介绍一些巧妙的语法，比如推导式，生僻但是好用，只是一般想不起来了，或者不利于菜鸟理解。
