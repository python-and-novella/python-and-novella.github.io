## 第七章 两位商人

### 001 一流的E流

“好久不见，苏菲。”

苏菲有些激动地说不出话，看着罗飞，一时间不知道手往哪放，几欲拥抱罗飞。

相比于苏菲，苏菲的手下显得更加热情，尤其是林风，作为地位仅次于苏菲的二把手，对于罗飞的态度让罗飞有些难以接受，抱住罗飞就要亲：“好久不见，我想死你了！”

罗飞急忙制止：“林兄，你对我也太热情了，大可不必。”

“你可是以后要成为‘老板娘’的，我要好好疏通一下我的仕途！”

罗飞的脸腾的一下就红了：“瞎说啥呢，我和苏菲就是普通的朋友关系，没你说的那种事情，我倒是觉得你有可能登上这个位置。”

一句话让林风有点不知所措：“我，我没有这种想法，她可是我们的老大，而且，你这说这话，不怕被当事人打吗？”

苏菲一拳捶在罗飞胸口：“真是的，别拿我最得力的干将开玩笑，你不接受也不能让别人尴尬啊。”

罗飞假装吃痛：“哎呦，你下手真狠，我要吐血了。”

苏菲见状，急忙抱住罗飞，想让他躺下，罗飞却狡黠一笑：“嘿嘿，逗你玩！”

“罗飞！”苏菲一跺脚，脸上又气又笑，让人难以捉摸。

嬉闹过后，该谈正事了。林风拿出一份星图给罗飞，示意罗飞打开看。

星图，类似于地图，只不过对于在星际穿行的人来说，要用更加专业的方法表示位置，才能确保穿梭于星际不会迷路。



（罗飞一开始找苏菲采购一个敏感的设备给白雨菲，通过星图得知，设备所在的地方比较危险，需要罗飞亲自去帮忙，好在是顺路，罗飞若是去帮忙可以提高成功率，还能减免运费）
